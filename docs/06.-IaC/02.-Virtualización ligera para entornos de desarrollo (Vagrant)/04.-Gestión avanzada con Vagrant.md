Vagrant permite gestionar entornos de desarrollo más complejos a través de configuraciones avanzadas, como la configuración de redes, la sincronización de carpetas, la creación de entornos multi-máquina y el uso de herramientas de **provisionamiento** como **shell scripts** y **Ansible**.


## Configuración de redes y sincronización de carpetas

### Configuración de redes en Vagrant

Por defecto, Vagrant configura la máquina virtual con una red **NAT** (Network Address Translation), pero es posible personalizar la conectividad utilizando distintos tipos de redes:

- **Red privada**: Permite que el host y la VM se comuniquen directamente.
- **Red pública**: La VM obtiene una dirección IP dentro de la red del host, haciéndola accesible desde otros dispositivos.

Ejemplo de configuración de redes en un `Vagrantfile`:

```ruby
Vagrant.configure("2") do |config|
  config.vm.box = "ubuntu/bionic64"

  # Red privada (IP fija)
  config.vm.network "private_network", ip: "192.168.56.10"

  # Red pública (con DHCP)
  config.vm.network "public_network"
end
```

**Comprobación de la red dentro de la VM:**

```bash
ip a
```

Esto mostrará las interfaces de red configuradas.


### Sincronización de carpetas entre el host y la VM

Vagrant permite compartir directorios entre el sistema anfitrión (host) y la máquina virtual (guest), facilitando el acceso a los archivos del proyecto desde ambos entornos.

Ejemplo de configuración en el `Vagrantfile`:

```ruby
Vagrant.configure("2") do |config|
  config.vm.box = "ubuntu/bionic64"

  # Sincronizar la carpeta del host con "/home/vagrant/proyecto" en la VM
  config.vm.synced_folder "./mi_proyecto", "/home/vagrant/proyecto"
end
```

Después de ejecutar `vagrant up`, los archivos dentro del directorio `mi_proyecto` en el host estarán accesibles en `/home/vagrant/proyecto` dentro de la VM.

## Creación de entornos multi-máquina

Vagrant permite definir múltiples máquinas en un mismo `Vagrantfile`, lo cual es útil para simular entornos de servidores distribuidos.

Ejemplo de configuración multi-máquina:

```ruby
Vagrant.configure("2") do |config|
  # Máquina 1: Servidor web
  config.vm.define "web" do |web|
    web.vm.box = "ubuntu/bionic64"
    web.vm.network "private_network", ip: "192.168.56.10"
  end

  # Máquina 2: Base de datos
  config.vm.define "db" do |db|
    db.vm.box = "ubuntu/bionic64"
    db.vm.network "private_network", ip: "192.168.56.11"
  end
end
```

Para iniciar las máquinas, se puede ejecutar:

```bash
vagrant up web
vagrant up db
```

O todas al mismo tiempo:

```bash
vagrant up
```

Para acceder a cada máquina:

```bash
vagrant ssh web
vagrant ssh db
```

## Provisionamiento con shell scripts y Ansible desde Vagrant

### Provisionamiento con Shell Scripts

Vagrant permite ejecutar **scripts de shell** automáticamente durante la creación de la máquina virtual. Esto es útil para instalar software y configurar el sistema de manera automatizada.

Ejemplo de provisionamiento con un script en línea:

```ruby
Vagrant.configure("2") do |config|
  config.vm.box = "ubuntu/bionic64"

  config.vm.provision "shell", inline: <<-SHELL
    sudo apt update
    sudo apt install -y nginx
    echo "Servidor web listo" | sudo tee /var/www/html/index.html
  SHELL
end
```

Cuando se ejecuta `vagrant up`, este script instala **NGINX** y crea una página de prueba.

También es posible usar **archivos externos**:

```ruby
config.vm.provision "shell", path: "setup.sh"
```

Donde `setup.sh` contiene las instrucciones a ejecutar dentro de la VM.


### Provisionamiento con Ansible
Ansible es una herramienta potente de **automatización y configuración** que se integra fácilmente con Vagrant. Para usarlo, se debe instalar el plugin de Vagrant para Ansible:

```bash
vagrant plugin install vagrant-ansible
```

Ejemplo de configuración en el `Vagrantfile`:

```ruby
Vagrant.configure("2") do |config|
  config.vm.box = "ubuntu/bionic64"

  # Provisionamiento con Ansible
  config.vm.provision "ansible" do |ansible|
    ansible.playbook = "provision.yml"
  end
end
```

Ejemplo de un playbook `provision.yml` que instala Apache:

```yaml
- hosts: all
  become: yes
  tasks:
    - name: Instalar Apache
      apt:
        name: apache2
        state: present
```

Al ejecutar `vagrant up`, Vagrant se encargará de aplicar la configuración de Ansible automáticamente.


## Conclusión
Las opciones avanzadas de Vagrant permiten gestionar redes, sincronizar archivos, trabajar con múltiples máquinas y automatizar la configuración mediante shell scripts y Ansible. Estas funcionalidades son esenciales para crear entornos de desarrollo flexibles y reproducibles.
