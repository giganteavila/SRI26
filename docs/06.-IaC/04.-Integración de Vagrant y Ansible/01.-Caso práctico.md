### **Caso práctico: Integración de Vagrant y Ansible**

En este caso práctico, configuraremos un **entorno multi-máquina** utilizando **Vagrant** para gestionar la creación de máquinas virtuales y **Ansible** para su aprovisionamiento y configuración. El objetivo es desplegar una infraestructura que incluya diferentes servicios de manera automatizada, asegurando un entorno consistente y fácilmente reproducible.

#### **Escenario del caso práctico**

Se diseñará un entorno con dos máquinas virtuales:

1. **Servidor web**: Una máquina que ejecutará un servidor **Apache** para servir páginas web.
2. **Servidor de base de datos**: Otra máquina que tendrá **MySQL** instalado y configurado para gestionar las bases de datos necesarias.

Vagrant se encargará de definir y crear las máquinas virtuales, mientras que Ansible automatizará la instalación y configuración de los servicios. El aprovisionamiento incluirá la instalación de paquetes necesarios, la configuración de los servicios y la conexión entre el servidor web y la base de datos.

Este enfoque permitirá a los desarrolladores y administradores de sistemas desplegar entornos completos con un solo comando, facilitando la replicación y mantenimiento de infraestructuras.
