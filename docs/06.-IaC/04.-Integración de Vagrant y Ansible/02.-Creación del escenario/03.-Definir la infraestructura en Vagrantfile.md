En el directorio del proyecto, creamos un archivo **Vagrantfile** con la configuración de las máquinas virtuales. Este archivo describe la infraestructura deseada:

```ruby
Vagrant.configure("2") do |config|

  # Definición de la primera máquina: Servidor web
  config.vm.define "web" do |web|
    web.vm.box = "ubuntu/focal64"
    web.vm.hostname = "webserver"
    web.vm.network "private_network", type: "dhcp"
    web.vm.provision "ansible" do |ansible|
      ansible.playbook = "playbook_web.yml"
    end
  end

  # Definición de la segunda máquina: Servidor de base de datos
  config.vm.define "db" do |db|
    db.vm.box = "ubuntu/focal64"
    db.vm.hostname = "dbserver"
    db.vm.network "private_network", type: "dhcp"
    db.vm.provision "ansible" do |ansible|
      ansible.playbook = "playbook_db.yml"
    end
  end

end
```

**Explicación del Vagrantfile:**

- Se definen dos máquinas: **web** (servidor web) y **db** (servidor de base de datos).
- Ambas usan la imagen base `ubuntu/focal64`.
- Se configuran en una red privada con **DHCP**.
- Se especifica que **Ansible** gestionará la configuración de cada máquina mediante sus respectivos **playbooks**.
