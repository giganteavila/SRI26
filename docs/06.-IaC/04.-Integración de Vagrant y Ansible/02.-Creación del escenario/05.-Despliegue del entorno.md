Una vez creados el **Vagrantfile** y los **playbooks de Ansible**, iniciamos las máquinas con:

```bash
vagrant up
```

Esto realizará los siguientes pasos automáticamente:

1. Descargar e iniciar las máquinas virtuales.
2. Configurarlas con los parámetros establecidos en el **Vagrantfile**.
3. Aprovisionarlas con Ansible, instalando los paquetes y configuraciones necesarias.

Para verificar que los servicios están activos, podemos conectarnos a las máquinas:

```bash
vagrant ssh web
```

Y ejecutar:

```bash
curl http://localhost
```

Debería mostrarse la página de Apache en caso de éxito.

Para el servidor de base de datos:

```bash
vagrant ssh db
```

Y probar la conexión a MySQL con:

```bash
mysql -u root -e "SHOW DATABASES;"
```
