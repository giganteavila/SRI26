Antes de comenzar, asegúrate de que las siguientes herramientas están instaladas en tu sistema:

- **Vagrant**: Para la gestión de máquinas virtuales.
- **VirtualBox** o **KVM/QEMU**: Como proveedor de virtualización.
- **Ansible**: Para la automatización de la configuración y el aprovisionamiento.

Para instalar estas herramientas en un sistema basado en Debian/Ubuntu:

```bash
sudo apt update
sudo apt install -y vagrant virtualbox ansible
```

Para sistemas basados en RHEL/CentOS:

```bash
sudo dnf install -y vagrant virtualbox ansible
```
