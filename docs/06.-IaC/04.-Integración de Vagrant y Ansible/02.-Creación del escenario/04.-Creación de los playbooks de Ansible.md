Ansible usará dos archivos **YAML** para configurar cada máquina virtual automáticamente.

### **Playbook para el servidor web (`playbook_web.yml`)**

Este archivo instalará **Apache** y lo iniciará:

```yaml
- name: Configuración del servidor web
  hosts: all
  become: yes
  tasks:
    - name: Instalar Apache
      apt:
        name: apache2
        state: present
        update_cache: yes

    - name: Habilitar Apache al inicio
      systemd:
        name: apache2
        enabled: yes
        state: started
```

------

### **Playbook para el servidor de base de datos (`playbook_db.yml`)**

Este archivo instalará **MySQL** y creará una base de datos básica:

```yaml
- name: Configuración del servidor de base de datos
  hosts: all
  become: yes
  tasks:
    - name: Instalar MySQL Server
      apt:
        name: mysql-server
        state: present
        update_cache: yes

    - name: Habilitar MySQL al inicio
      systemd:
        name: mysql
        enabled: yes
        state: started

    - name: Crear una base de datos
      mysql_db:
        name: mi_base_datos
        state: present
```

**Explicación de los playbooks:**

- Se instalan los servicios respectivos en cada servidor (**Apache en `web`**, **MySQL en `db`**).
- Se configuran para ejecutarse automáticamente al inicio del sistema.
- En el caso de MySQL, se crea una base de datos llamada `mi_base_datos`.
