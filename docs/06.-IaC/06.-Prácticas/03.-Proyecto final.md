## Objetivo

El objetivo del proyecto final es diseñar, desplegar y automatizar una infraestructura completa utilizando **Vagrant** para la gestión de máquinas virtuales, **Ansible** para la automatización de la configuración y **Docker** para el despliegue de servicios.

## Requisitos

El proyecto debe cumplir con los siguientes criterios mínimos:

- Dos o más máquinas virtuales gestionadas con Vagrant, con al menos:
	- Un **servidor web** que ejecute un contenedor de Nginx o Apache.
	- Un **servidor de base de datos** que ejecute un contenedor de MySQL o PostgreSQL.
   
- Provisionamiento automático con Ansible, incluyendo:
	- Instalación y configuración de Docker en ambas máquinas.
	- Creación y ejecución de contenedores con los servicios necesarios.
	- Configuración de seguridad básica (cortafuegos, usuarios, permisos).

- **Conectividad entre los servicios**, asegurando que la aplicación web pueda acceder a la base de datos.

- **Uso de control de versiones con Git**, manteniendo la configuración del proyecto en un repositorio.
