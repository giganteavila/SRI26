# 06.-Prácticas

En estas prácticas consolidarás tus conocimientos en Infraestructura como Código (IaC) mediante la implementación y automatización de entornos virtualizados con Vagrant y Ansible. Aprenderás a gestionar máquinas virtuales, escribir playbooks y automatizar despliegues de manera eficiente y escalable.

Además de los ejercicios individuales, desarrollarás un proyecto final donde diseñarás y desplegarás una infraestructura completa con Vagrant y Ansible. Aplicarás buenas prácticas, control de versiones con Git y seguridad con Ansible Vault para asegurar un entorno óptimo.
