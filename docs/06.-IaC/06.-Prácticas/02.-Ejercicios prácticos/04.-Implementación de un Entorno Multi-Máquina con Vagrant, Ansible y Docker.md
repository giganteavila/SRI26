**Objetivo:** Configurar un entorno con múltiples máquinas virtuales gestionadas con Vagrant, provisionadas con Ansible y con Docker instalado para desplegar contenedores en el servidor web y la base de datos.

## Configurar Vagrant con dos máquinas

Crea un directorio de trabajo y dentro de él, un archivo `Vagrantfile` con el siguiente contenido:

```ruby
Vagrant.configure("2") do |config|
  # Máquina Web
  config.vm.define "web" do |web|
    web.vm.box = "ubuntu/bionic64"
    web.vm.network "private_network", ip: "192.168.33.10"
    web.vm.provision "ansible" do |ansible|
      ansible.playbook = "playbook_web.yml"
    end
  end

  # Máquina de Base de Datos
  config.vm.define "db" do |db|
    db.vm.box = "ubuntu/bionic64"
    db.vm.network "private_network", ip: "192.168.33.11"
    db.vm.provision "ansible" do |ansible|
      ansible.playbook = "playbook_db.yml"
    end
  end
end
```

Levanta las máquinas con:

```bash
vagrant up
```

## Configurar Ansible para automatizar la instalación

Crea un archivo `inventory` con las IPs de las máquinas:

```ini
[web]
192.168.33.10 ansible_user=vagrant ansible_ssh_private_key_file=~/.vagrant.d/insecure_private_key

[db]
192.168.33.11 ansible_user=vagrant ansible_ssh_private_key_file=~/.vagrant.d/insecure_private_key
```



## Configurar el Servidor Web con Docker y Nginx

Crea un `playbook_web.yml` para instalar Docker, desplegar un contenedor con Nginx y servir una página web:

```yaml
- hosts: web
  become: yes
  tasks:
    - name: Instalar dependencias
      apt:
        name: ["apt-transport-https", "ca-certificates", "curl", "software-properties-common"]
        state: present
        update_cache: yes

    - name: Agregar clave GPG de Docker
      shell: curl -fsSL https://download.docker.com/linux/ubuntu/gpg | apt-key add -

    - name: Agregar repositorio de Docker
      shell: add-apt-repository "deb [arch=amd64] https://download.docker.com/linux/ubuntu bionic stable"

    - name: Instalar Docker
      apt:
        name: docker-ce
        state: present
        update_cache: yes

    - name: Iniciar y habilitar Docker
      service:
        name: docker
        state: started
        enabled: yes

    - name: Descargar imagen de Nginx
      docker_image:
        name: nginx
        source: pull

    - name: Crear y ejecutar contenedor Nginx
      docker_container:
        name: webserver
        image: nginx
        state: started
        ports:
          - "80:80"
```

## Configurar el Servidor de Base de Datos con Docker y MySQL

Crea un `playbook_db.yml` para instalar Docker y desplegar un contenedor de MySQL:

```yaml
- hosts: db
  become: yes
  tasks:
    - name: Instalar dependencias
      apt:
        name: ["apt-transport-https", "ca-certificates", "curl", "software-properties-common"]
        state: present
        update_cache: yes

    - name: Agregar clave GPG de Docker
      shell: curl -fsSL https://download.docker.com/linux/ubuntu/gpg | apt-key add -

    - name: Agregar repositorio de Docker
      shell: add-apt-repository "deb [arch=amd64] https://download.docker.com/linux/ubuntu bionic stable"

    - name: Instalar Docker
      apt:
        name: docker-ce
        state: present
        update_cache: yes

    - name: Iniciar y habilitar Docker
      service:
        name: docker
        state: started
        enabled: yes

    - name: Descargar imagen de MySQL
      docker_image:
        name: mysql
        source: pull

    - name: Crear y ejecutar contenedor MySQL
      docker_container:
        name: mysql_db
        image: mysql
        state: started
        env:
          MYSQL_ROOT_PASSWORD: rootpassword
          MYSQL_DATABASE: mi_basedatos
          MYSQL_USER: usuario
          MYSQL_PASSWORD: password123
        ports:
          - "3306:3306"
```



## Ejecutar Ansible y probar la configuración

Ejecuta los playbooks con:

```bash
ansible-playbook -i inventory playbook_web.yml
ansible-playbook -i inventory playbook_db.yml
```

## Verificar la configuración

- **Servidor Web:**
	- Visita `http://192.168.33.10` en tu navegador y verifica que el servidor **Nginx en Docker** está funcionando.

- **Base de Datos:**
	- Conéctate a MySQL desde la máquina web con:

```bash
    mysql -h 192.168.33.11 -u usuario -p
```

## Resultados esperados
- Un **servidor web** con Nginx ejecutándose dentro de un contenedor Docker en `192.168.33.10`.
- Un **servidor de base de datos** con MySQL en un contenedor Docker en `192.168.33.11`.
- Automatización completa con **Vagrant y Ansible**, sin necesidad de configurar manualmente los servicios.
