**Objetivo:** Configurar un entorno con múltiples máquinas virtuales gestionadas con Vagrant y provisionadas con Ansible. Una de las máquinas actuará como servidor web y otra como base de datos.

#### Configurar Vagrant con dos máquinas

- Crea un directorio de trabajo y dentro de él, un archivo `Vagrantfile` con el siguiente contenido:

```ruby
Vagrant.configure("2") do |config|
  # Definir máquina Web
  config.vm.define "web" do |web|
    web.vm.box = "ubuntu/bionic64"
    web.vm.network "private_network", ip: "192.168.33.10"
    web.vm.provision "ansible" do |ansible|
      ansible.playbook = "playbook_web.yml"
    end
  end

  # Definir máquina de Base de Datos
  config.vm.define "db" do |db|
    db.vm.box = "ubuntu/bionic64"
    db.vm.network "private_network", ip: "192.168.33.11"
    db.vm.provision "ansible" do |ansible|
      ansible.playbook = "playbook_db.yml"
    end
  end
end
```

- Levanta ambas máquinas con:

```bash
   vagrant up
```

#### Configurar Ansible para automatizar la instalación

Crea un archivo de inventario `inventory` para Ansible:

```ini
[web]
192.168.33.10 ansible_user=vagrant ansible_ssh_private_key_file=~/.vagrant.d/insecure_private_key

[db]
192.168.33.11 ansible_user=vagrant ansible_ssh_private_key_file=~/.vagrant.d/insecure_private_key
```

##### Playbook para el servidor web (`playbook_web.yml`)

Crea un `playbook_web.yml` que instale Apache y sirva una página HTML básica:

```yaml
- hosts: web
  become: yes
  tasks:
    - name: Instalar Apache
      apt:
        name: apache2
        state: present
        update_cache: yes

    - name: Copiar página de prueba
      copy:
        content: "<h1>¡Servidor Web en Vagrant!</h1>"
        dest: /var/www/html/index.html
        mode: '0644'

    - name: Iniciar y habilitar Apache
      service:
        name: apache2
        state: started
        enabled: yes
```

##### Playbook para la base de datos (`playbook_db.yml`)

Crea un `playbook_db.yml` que instale MySQL y configure un usuario y base de datos:

```yaml
- hosts: db
  become: yes
  tasks:
    - name: Instalar MySQL
      apt:
        name: mysql-server
        state: present
        update_cache: yes

    - name: Iniciar y habilitar MySQL
      service:
        name: mysql
        state: started
        enabled: yes

    - name: Crear base de datos
      mysql_db:
        name: mi_basedatos
        state: present

    - name: Crear usuario de base de datos
      mysql_user:
        name: usuario
        password: password123
        priv: 'mi_basedatos.*:ALL'
        host: '%'
        state: present
```

#### Ejecutar Ansible y probar la configuración

- Aplica la configuración con:

```bash
   ansible-playbook -i inventory playbook_web.yml
   ansible-playbook -i inventory playbook_db.yml
```

- Comprueba que la página web está funcionando visitando `http://192.168.33.10` en tu navegador.

- Accede a la base de datos en la máquina **db** y verifica que la base de datos y el usuario han sido creados:

```bash
   mysql -u usuario -p
```

### Resultados esperados

- Un **servidor web** funcionando en `192.168.33.10`.
- Un **servidor de base de datos** en `192.168.33.11` con MySQL configurado.
- Automatización completa mediante **Ansible**, sin necesidad de configuración manual.

Este ejercicio introduce la gestión de entornos multi-máquina y el aprovisionamiento con Ansible, acercándose a escenarios reales de infraestructura como código.
