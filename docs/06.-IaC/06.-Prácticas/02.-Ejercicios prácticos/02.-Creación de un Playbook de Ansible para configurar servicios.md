### **Ejercicio 2: Creación de un Playbook de Ansible para configurar servicios**

**Objetivo:** Aprender a automatizar la configuración de un servidor con Ansible.

- Instala **Ansible** en tu sistema.

- Crea un directorio de proyecto y dentro de él, un archivo `inventory` con la dirección de tu máquina Vagrant:

```
   [servidores]
   192.168.33.10 ansible_user=vagrant ansible_ssh_private_key_file=~/.vagrant.d/insecure_private_key
```

- Crea un `playbook.yml` que realice las siguientes tareas en la máquina:
	- Actualizar los paquetes del sistema
	- Instalar Apache
	- Iniciar y habilitar el servicio Apache

- El contenido del `playbook.yml` debería ser similar a este:
```yaml
   - hosts: servidores
     become: yes
     tasks:
       - name: Actualizar paquetes
         apt:
           update_cache: yes
       
       - name: Instalar Apache
         apt:
           name: apache2
           state: present
   
       - name: Iniciar y habilitar Apache
         service:
           name: apache2
           state: started
           enabled: yes
```
- Ejecuta el playbook con:

```bash
   ansible-playbook -i inventory playbook.yml
```

- Verifica que Apache está funcionando accediendo a `http://192.168.33.10` desde tu navegador.
