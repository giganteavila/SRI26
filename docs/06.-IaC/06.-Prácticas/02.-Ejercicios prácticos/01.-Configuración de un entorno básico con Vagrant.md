**Objetivo:** Aprender a crear y gestionar máquinas virtuales con Vagrant.

- Instala **Vagrant** y KVM/QEMU.

- Crea un directorio de trabajo y dentro de él, inicializa un nuevo `Vagrantfile` con el siguiente comando:

```bash
	vagrant init ubuntu/bionic64
```

- Modifica el `Vagrantfile` para que la máquina tenga:
	- 2 GB de RAM
	- 2 CPU
	- Una carpeta compartida entre el host y la VM

- Inicia la máquina con:

```bash
	vagrant up
```

- Accede a la máquina mediante SSH y comprueba su conectividad con `ping 8.8.8.8`.

- Detén y elimina la máquina con:

```bash
	vagrant halt
	vagrant destroy
```
