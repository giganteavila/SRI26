### 03.- Comandos básicos de Ansible

#### `ansible`

El comando `ansible` permite ejecutar tareas ad hoc en sistemas remotos sin necesidad de escribir un playbook. Se usa principalmente para probar conectividad o ejecutar comandos simples.

Ejemplo de verificación de conectividad con los hosts definidos en el inventario:

```sh
ansible all -m ping
```

Ejemplo de ejecución de un comando en los hosts remotos:

```sh
ansible all -m command -a "uptime"
```

#### `ansible-playbook`

El comando `ansible-playbook` se usa para ejecutar playbooks de Ansible, que contienen una serie de tareas definidas en formato YAML.

Ejemplo de ejecución de un playbook:

```sh
ansible-playbook playbook.yml
```

Para especificar un inventario personalizado:

```sh
ansible-playbook -i inventario.ini playbook.yml
```

#### `ansible-vault`

El comando `ansible-vault` permite gestionar datos sensibles cifrados dentro de Ansible, como contraseñas o claves de acceso.

- Crear un archivo cifrado:

  ```sh
  ansible-vault create secreto.yml
  ```

- Editar un archivo cifrado:

  ```sh
  ansible-vault edit secreto.yml
  ```

- Cifrar un archivo existente:

  ```sh
  ansible-vault encrypt archivo.yml
  ```

- Desencriptar un archivo:

  ```sh
  ansible-vault decrypt archivo.yml
  ```

- Ejecutar un playbook que usa un archivo cifrado:

  ```sh
  ansible-playbook --ask-vault-pass playbook.yml
  ```

#### Ejecución de tareas en sistemas remotos

Ansible permite ejecutar tareas en sistemas remotos de forma sencilla. Por ejemplo, para instalar un paquete en servidores basados en Debian:

```sh
ansible all -m apt -a "name=nginx state=present" --become
```

Para reiniciar un servicio:

```sh
ansible all -m service -a "name=nginx state=restarted" --become
```

Estos comandos básicos permiten gestionar sistemas remotos de manera eficiente con Ansible.
