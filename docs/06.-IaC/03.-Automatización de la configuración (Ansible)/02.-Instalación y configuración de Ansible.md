### 02.- Instalación y configuración de Ansible

#### Instalación en Linux

Para instalar Ansible en un sistema Linux, se pueden utilizar los siguientes métodos según la distribución:

**En Debian/Ubuntu:**

```sh
sudo apt update
sudo apt install ansible -y
```

**En RHEL/CentOS:**

```sh
sudo dnf install ansible -y
```

**En Arch Linux:**

```sh
sudo pacman -S ansible
```

Para verificar la instalación, se puede ejecutar:

```sh
ansible --version
```

#### Configuración básica del inventario

El inventario en Ansible define los servidores que se administrarán. Se encuentra en `/etc/ansible/hosts` o en un archivo personalizado.

Ejemplo de un archivo de inventario:

```ini
[webservers]
192.168.1.10
192.168.1.11

[dbservers]
192.168.1.20
```

Se pueden probar los servidores con el siguiente comando:

```sh
ansible all -m ping -i inventario.ini
```

Esto verificará la conectividad con los servidores listados en el inventario.
