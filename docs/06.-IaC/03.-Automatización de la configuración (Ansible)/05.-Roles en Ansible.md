### 05.- Roles en Ansible

#### Organización de tareas complejas

Los roles en Ansible permiten organizar tareas, variables y archivos en una estructura modular y reutilizable. Esto facilita la gestión de configuraciones complejas y promueve la reutilización del código.

Para crear un rol en Ansible, se utiliza el siguiente comando:

```sh
ansible-galaxy init nombre_del_rol
```

Esto genera una estructura de directorios estándar:

```plaintext
nombre_del_rol/
├── defaults/      # Variables por defecto
├── files/         # Archivos estáticos a copiar
├── handlers/      # Manejadores de eventos (ej. reiniciar servicios)
├── meta/          # Metadatos del rol
├── tasks/         # Lista de tareas a ejecutar
├── templates/     # Archivos Jinja2 con variables
├── vars/          # Variables específicas del rol
```

Para utilizar un rol en un playbook:

```yaml
- hosts: servidores
  roles:
    - nombre_del_rol
```

#### Uso de Galaxy para importar roles

Ansible Galaxy es un repositorio en línea de roles compartidos por la comunidad. Se pueden descargar e importar roles predefinidos utilizando:

```sh
ansible-galaxy install usuario.rol
```

Por ejemplo, para instalar un rol que configura Nginx:

```sh
ansible-galaxy install geerlingguy.nginx
```

Luego, se puede incluir el rol en un playbook:

```yaml
- hosts: servidores
  roles:
    - geerlingguy.nginx
```

El uso de roles y Ansible Galaxy permite optimizar la automatización de configuraciones complejas y compartir mejores prácticas dentro de la comunidad Ansible.
