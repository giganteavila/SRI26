**Objetivo:** Implementar un algoritmo de machine learning (como un modelo de clasificación o regresión) para predecir y optimizar el tráfico de red en función de datos históricos.

**Pasos:**

- **Recopilación de datos de tráfico de red:**
	- Usa herramientas como **Wireshark** o **NetFlow** para capturar datos de tráfico de red en un entorno de laboratorio.
	- Extrae métricas relevantes como el ancho de banda, el tipo de tráfico, la latencia y los picos de tráfico.
- **Preprocesamiento de datos:**
	- Utiliza **Python** y bibliotecas como **pandas** y **scikit-learn** para limpiar y preparar los datos.
	- Realiza una normalización de los datos para que estén en un formato adecuado para el algoritmo de IA.
- **Entrenamiento de un modelo de predicción:**
	- Utiliza un modelo de regresión o clasificación (por ejemplo, **Regresión Logística** o **Redes Neuronales Artificiales**) para predecir el comportamiento del tráfico en función de los datos de entrada.
	- Entrena el modelo con datos históricos de tráfico y prueba su precisión.
- **Aplicación del modelo:**
	- Implementa el modelo entrenado para predecir el tráfico futuro y optimizar dinámicamente los recursos de red (como el enrutamiento del tráfico) utilizando IA.

**Herramientas:** Python, scikit-learn, pandas, Wireshark, NetFlow.

**Resultado esperado:** Un modelo de IA que prediga los picos de tráfico en la red y ajuste los recursos en tiempo real para evitar congestiones.
