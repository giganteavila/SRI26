# **Configuración del Sistema de Ficheros 9P**

Este manual detalla el proceso para compartir una carpeta entre un sistema anfitrión (Host) y una máquina virtual (Guest), ambos ejecutando Debian 13, utilizando el sistema de ficheros 9P con KVM/QEMU en modo sesión.

### **Escenario**

- **Sistema Operativo (Host y Guest):** Debian 13 "Trixie"  
- **Software de Virtualización:** QEMU/KVM en modo sesión (gestionado por el usuario).  
- **Usuario del Host:** `asir`  
- **Usuario del Guest:** `asir` (con permisos de `sudo`)  
- **Nombre de la Carpeta a Compartir:** `Compartida`  
- **Punto de Montaje (Tag):** `Compartida`

## **Parte 1: Configuración en el Sistema Anfitrión (Host)**

El primer paso es crear la carpeta que se va a compartir y asegurarse de que el usuario `asir` tiene los permisos correctos sobre ella.

### **1.1. Crear la Carpeta Compartida**

Abre una terminal en el sistema anfitrión y ejecuta el siguiente comando para crear la carpeta `Compartida` en el directorio personal del usuario `asir`.

```bash
mkdir /home/asir/Compartida
```

### **1.2. Modificar el Comando de Arranque de QEMU**

Para que QEMU pueda exponer la carpeta al sistema invitado, necesitas añadir dos parámetros a tu comando de arranque de la máquina virtual.

1. `-fsdev`: Define el backend del sistema de ficheros en el host.  
   * `local`: Indica que es un directorio local.  
   * `id=fsdev0`: Un identificador único para este dispositivo.  
   * `path=/home/asir/Compartida`: La ruta a la carpeta que creaste.  
   * `security_model=passthrough`: Este es el modelo de seguridad más directo. Permite que el sistema invitado acceda a los ficheros con los mismos permisos que el usuario asir del host. Es crucial para que la correspondencia de usuarios funcione correctamente.  
2. `-device`: Expone el backend `fsdev` al invitado como un dispositivo PCI.  
   * `virtio-9p-pci`: El tipo de dispositivo virtual que utiliza el protocolo 9P.  
   * `id=fs0`: Un identificador único para el dispositivo PCI.  
   * `fsdev=fsdev0`: Vincula este dispositivo al `fsdev` que definimos antes.  
   * `mount_tag=Compartida`: Esta es la "etiqueta" o nombre que el sistema invitado usará para identificar y montar el recurso compartido.

#### **Ejemplo de comando de arranque:**

Tu comando para iniciar la VM podría parecerse a esto. Los parámetros importantes son los que están al final. 
```bash
qemu-system-x86_64 \  
-m 2G \  
-enable-kvm \  
-hda mi_vm_debian13.qcow2 \  
# ... otros parámetros de tu VM ...  
-fsdev local,id=fsdev0,path=/home/asir/Compartida,security_model=passthrough \  
-device virtio-9p-pci,id=fs0,fsdev=fsdev0,mount_tag=Compartida
```
> **Nota:** Si utilizas `virt-manager` (libvirt), tendrías que añadir un "Filesystem" en la configuración de hardware de la VM, especificando la ruta del host, el punto de montaje y seleccionando el modo "Mapped" o "Passthrough". Para este manual, nos centramos en el comando directo de QEMU. 

Una vez modificada la configuración, inicia la máquina virtual. El host ya está listo.

## **Parte 2: Configuración en el Sistema Invitado (Guest)**

Ahora, dentro de la máquina virtual Debian 13, realizaremos los pasos para acceder a la carpeta compartida.

### **2.1. Crear el Punto de Montaje**

Al igual que en el host, necesitas una carpeta en el guest que sirva como punto de montaje para el recurso compartido.
```bash
# Como usuario 'asir' en el guest  
mkdir /home/asir/Compartida
```
### **2.2. Montar el Sistema de Ficheros 9P**

Utiliza el comando mount para conectar el recurso compartido expuesto por QEMU (mount_tag) con el directorio que acabas de crear.  
Ejecuta este comando en la terminal del guest:  
```bash
sudo mount -t 9p -o trans=virtio,version=9p2000.L,msize=104857600,fmask=0022,dmask=0022 Compartida ~/Compartida
```
#### **Desglose de las opciones de montaje:**

* `-t 9p`: Especifica que el tipo de sistema de ficheros es 9p.  
* `-o`: Indica que a continuación vienen las opciones de montaje.  
  * `trans=virtio`: El transporte a utilizar. `virtio` es el estándar para dispositivos paravirtualizados en KVM/QEMU, ofreciendo el mejor rendimiento.  
  * `version=9p2000.L`: Especifica la versión del protocolo 9P. 9p2000.L es una extensión de Linux que incluye soporte para características de sistemas de ficheros modernos como los permisos extendidos.  
  * `msize=104857600`: Define el tamaño máximo de los mensajes del protocolo en bytes (100 MiB en este caso). Aumentar este valor puede mejorar el rendimiento en la transferencia de ficheros grandes.  
  * `fmask=0022` y `dmask=0022`: Estas máscaras de permisos aseguran que los ficheros (`fmask`) y directorios (`dmask`) creados desde el guest tengan los permisos correctos (`-rw-r--r--` para ficheros y `drwxr-xr-x` para directorios), evitando que otros usuarios puedan escribir en ellos.  
* `Compartida`: Es el `mount_tag` que definiste en el comando de QEMU.  
* `~/Compartida`: Es la ruta del punto de montaje en el sistema guest.

### **2.3. Verificación**

Para comprobar que todo ha funcionado, puedes crear un fichero en el host y ver si aparece en el guest, y viceversa.

* **En el Host:** 
```bash
  echo "Hola desde el Host" > /home/asir/Compartida/test_host.txt
```
* **En el Guest:**  
```bash
  cat ~/Compartida/test_host.txt  
  # Deberías ver "Hola desde el Host"  
  echo "Respuesta desde el Guest" > ~/Compartida/test_guest.txt
```
## **Parte 3: Hacer el Montaje Permanente (Opcional)**

Para que la carpeta se monte automáticamente cada vez que inicies la máquina virtual, debes añadir una entrada al fichero `/etc/fstab` del sistema guest.

### **3.1. Editar el Fichero `fstab`**

Abre el fichero con un editor de texto como nano:  
```bash
sudo nano /etc/fstab
```

### **3.2. Añadir la Línea de Montaje**

Añade la siguiente línea al final del fichero:
```bash
# Montaje de la carpeta compartida con el host  
Compartida   /home/asir/Compartida   9p   trans=virtio,version=9p2000.L,msize=104857600,fmask=0022,dmask=0022,_netdev   0   0
```
* La opción `_netdev` es importante. Le indica al sistema que este es un "dispositivo de red" (aunque sea virtual) y que debe esperar a que la red esté disponible antes de intentar montarlo. Esto previene errores durante el arranque si el dispositivo 9P no está listo inmediatamente.

Guarda el fichero (`Ctrl+O` en nano) y sal (`Ctrl+X`).

### **3.3. Probar el Montaje de fstab**

Puedes probar si la línea de fstab es correcta sin necesidad de reiniciar. Primero, desmonta la carpeta si sigue montada:
```bash
sudo umount ~/Compartida
```
Y luego, pide al sistema que monte todo lo que está en fstab:  
```bash
sudo mount -a
```

Si no aparece ningún error, la configuración es correcta y la carpeta se montará automáticamente en el próximo reinicio.
